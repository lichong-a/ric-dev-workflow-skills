# SQL

仅当范围涉及 SQL 查询、Schema、迁移或数据库契约时，加载本参考。

- 确认精确数据库/版本、Driver/ORM、迁移工具、隔离级别和命名约定。SQL 方言和 DDL 锁行为并不通用。
- 绑定所有值；无法参数化的标识符必须使用 allowlist。显式选择列，限定含糊列名，定义确定性排序，并限制结果集大小。
- 审核 null/三值逻辑、时区、Decimal 精度、Collation、Unicode、Enum/Check 行为、Join 产生的重复行和竞争安全的唯一性。
- 用约束保护持久不变量，并协调应用错误处理。根据真实谓词、选择性、Join 和排序设计索引，同时考虑写入/存储成本和重复索引。
- 对重要查询和有代表性数据形态检查执行计划；在会产生实质影响时避免 N+1、全表扫描、隐式 Cast、逐行函数和大 Offset 分页。
- 事务保持短小，并明确锁/隔离/死锁重试。滚动兼容或大数据需要时，迁移遵循“扩展 → 回填 → 切换 → 收缩”，并提供可观测性和恢复方案。
- 测试必须覆盖约束、并发/竞争、迁移兼容性和租户作用域，不得使用敏感生产样本。
