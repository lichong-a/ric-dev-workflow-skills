# AI 与 Agent 审核

当范围涉及 Prompt、模型调用、工具契约、检索、Agent 循环、评测或 AI 生成动作时，加载本参考。

## 契约与权限

通过运行时校验定义模型输入/输出、工具名称与 Schema、权限范围、副作用、幂等键、超时、取消、重试和用户确认边界。将模型输出视为不可信输入。Prompt 不能授予调用者本身没有的权限，模型响应成功也不能证明工具副作用已实际发生。

将只读推理与外部写操作分离。在执行破坏性、公开、生产、付费、凭据或敏感操作前，必须即时取得最新授权。限制循环次数、并行调用、上下文大小、费用、墙上时间和重试次数；明确暴露部分失败和无法确认是否完成的状态。

## Prompt 与上下文安全

区分 system/developer 指令、用户请求、检索内容、工具输出、记忆和外部文档。检索内容和工具内容是数据，不是指令。防御 Prompt 注入、工具结果伪造、跨租户检索、secret 外泄、不安全 URL/文件处理，以及敏感 Prompt/日志留存。执行边界使用最小权限工具和明确 allowlist。

## 非确定性与评测

定义可观察成功标准和可接受差异。构建具代表性的评测集，覆盖正常场景、含糊请求、对抗/注入内容、工具失败、过期或冲突上下文、重复执行和授权拒绝。报告中固定模型、Prompt 和工具版本，但避免只比较措辞；应评价任务结果、安全不变量和产物正确性。更换模型或 Prompt 前，对照基线比较质量、延迟、成本和失败率。

## 可靠性与可观测性

为重复调用设计去重与对账；区分瞬时和永久失败；保持模型与工具之间的 Trace/关联信息；对敏感内容脱敏；记录模型、Prompt、工具版本及 Token/成本/延迟，但不得记录 secret。对后果重大且结果不确定的情况提供人工审核或恢复路径。
